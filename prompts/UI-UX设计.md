## 示例

```text
请帮我完成以下 UI/UX 设计：

**界面/交互名称**：物品栏 UI

**所属游戏/场景**：庭院灵踪 - 主界面常驻系统

**玩家操作入口**：键盘按 I 键 / 手柄按 Y 键 / 触屏点击右下角背包图标

**界面核心功能**：查看、整理、使用、丢弃玩家背包中的道具，支持按分类筛选与搜索

**界面结构/布局描述**：
- 左侧：分类 Tab（全部 / 消耗品 / 材料 / 任务物品 / 装备），纵向排列，当前选中高亮
- 中间：物品网格区域，5 列 × 6 行，每项显示图标 + 数量角标，鼠标悬停显示 Tooltip
- 右侧：详情面板，显示物品大图、名称、品质（颜色边框）、描述文字、属性/效果、"使用/装备"按钮
- 底部：容量进度条（如 24/30）+ "关闭" 按钮

**视觉风格要求**：
- 整体：国风淡雅，宣纸质感底纹 + 水墨勾勒边框
- 色彩：主色米白 (#F5F0E8)，强调色黛青 (#3D5A5A)，稀有度按 白→绿→蓝→紫→金 渐变
- 字体：标题用楷体，正文用思源宋体
- 装饰元素：四角云纹点缀，分类 Tab 带竹叶剪影

**交互流程**：
1. 玩家按 I 键 → 界面从屏幕中央淡入并轻微缩放弹出，背景加半透明遮罩
2. 默认选中"全部"Tab，网格展示所有物品
3. 点击分类 Tab → 网格平滑切换到对应分类物品，播放横向滑动过渡
4. 点击物品格 → 右侧详情面板更新为该物品信息
5. 右键物品 → 弹出操作菜单（使用 / 丢弃 / 拆分）
6. 按 Esc 或点击"关闭"按钮 → 界面淡出缩回，返回游戏

**可复用组件清单**：
- 分类 Tab 栏（已在商店 UI 使用）
- 物品格（Icon + 数量角标 + Hover Tooltip）
- 品质色边框（按稀有度配置的 Frame）
- 通用按钮样式（黛青描边 + 悬停加深）

**适配要求**：
- PC：1920×1080 基准，支持 1280×720 至 2560×1440 等比缩放
- 手柄：所有焦点可通过方向键/摇杆导航，选中项有明显高亮框
- 触屏：按钮热区 ≥ 44×44 px，支持长按触发堆叠物品拆分

**技术约束**：
- 必须使用 Unity UI Toolkit (UIElements) 实现
- 不能用 DOTween 以外的第三方补间库
- 所有 sprite 需保留 9-slice 信息以支持缩放

**验收标准**：
- 视觉效果：国风调性统一，各分辨率下布局不溢出、不变形，物品品质色一眼可辨
- 交互流畅度：打开/关闭动画 ≤ 300ms，Tab 切换过渡 ≤ 200ms，手柄导航无焦点丢失
```
