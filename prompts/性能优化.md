## 示例

```text
请帮我进行性能优化：

**问题描述**：关卡加载后出现严重卡顿，3 秒内 FPS 掉到 20 以下，之后逐渐恢复但仍不稳定。

**发生场景**：庭院灵踪关卡，玩家从主菜单进入关卡或通过传送门切换到该关卡时必现。

**性能指标数据**：
- 加载阶段：FPS 58 → 18（最低 14），持续约 3 秒
- 内存占用：加载前 3.2GB → 加载后 7.8GB（持续上涨）
- CPU：GameThread 峰值 92%，RenderThread 峰值 78%
- GPU：显存占用 4.1GB，Draw Call 峰值 2400+
- 关卡加载耗时：首次 45 秒，二次 28 秒

**复现步骤**：
1. 启动游戏，进入主菜单
2. 选择"庭院灵踪"关卡并点击开始
3. 观察加载完成后前 5 秒的帧率表现

**当前实现概要**：关卡包含约 200 个 StaticMesh Actor，3 个 SkeletalMesh，天空光 + 固定光源，使用统一光照贴图。加载时一次性同步加载所有资产，蓝图 Construction Script 中执行了大量碰撞检测和计算逻辑。

**已做过的尝试**：
- 禁用了 Lumen 全局光照明，改为烘焙：FPS 提升不明显
- 将部分贴图从 4K 降为 2K：内存减少约 800MB，卡顿仍存在
- 用 Unreal Insights 采样，发现 GameThread 卡在 ULevel::InitializeRenderingResources

**目标指标**：
- 关卡加载完成后稳定 60 FPS，最低不低于 45
- 内存峰值控制在 6GB 以内
- 首次加载时间降至 20 秒以内

**技术栈/运行平台**：Unreal Engine 5.3 + C++ / Blueprint，Windows 10，i7-12700K + RTX 3070

**约束**：
- 不能修改核心渲染模块
- 不能新增第三方依赖插件
- 关卡美术资产（模型、贴图）保持现有质量，不能降质
- 包体积不能增加
```
