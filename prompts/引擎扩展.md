## 示例

```text
请帮我为引擎扩展以下模块：

**扩展模块名称**：TileMap 瓦片地图系统

**目标（解决什么问题/添加什么能力）**：
支持基于瓦片图集（tileset）的 2D 地图渲染、碰撞检测与层级排序，
让关卡设计师能通过 Tiled 导出的 JSON 快速搭建关卡，无需手写坐标。

**所属引擎**：Asitch v0.1

**类型**：新系统

**API 设计草稿（类/方法/事件名）**：
- TileMap 类：load(jsonPath) / render(ctx, camera) / getTile(x, y)
- TileSet 类：fromImage(img, tileW, tileH) / getTileImage(index)
- 事件：onTileMapLoaded / onTileCollision

**依赖关系（需要哪些已有模块/能否独立使用）**：
- 依赖 Renderer2D（drawImage / sort 功能）
- 依赖 Camera（视口裁剪）
- 依赖 EventBus（事件派发）
- TileSet 可独立使用，TileMap 需以上三者

**性能约束（帧率/内存上限）**：
- 单帧渲染 50×50 瓦片不超过 0.3ms
- TileMap 实例内存 < 2MB（含 3 层图层）
- 禁用相机视口外瓦片的 drawCall

**文件位置建议**：src/systems/TileMap.js、src/systems/TileSet.js

**公开接口清单**：
- new TileMap(config)
- tileMap.load(src): Promise<void>
- tileMap.render(ctx, camera): void
- tileMap.getCollisionTiles(x, y): Tile[]
- tileMap.on(event, handler): void

**验收标准**：
- 功能：加载 Tiled 导出的 JSON 后能正确渲染地图，碰撞层与角色物理系统联动生效
- 性能：在 1024×768 视口下 60fps 稳定运行，内存占用符合约束
- 可维护性：TileMap 与 TileSet 职责分离，碰撞逻辑通过事件派发便于替换实现
```
